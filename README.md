# CampusOne

> **One Platform. Everything College.**

CampusOne is a student-centric academic workspace designed to turn
scattered college study materials into one curated, syllabus-driven
learning experience.

## Problem

College study resources are scattered across WhatsApp, Google Drive,
Telegram, YouTube, college LMS/ERP portals, and senior networks.
Students spend valuable study time searching for notes, previous-year
questions, lab material, videos, and exam information.

> **Students don't lack study material. They lack one organized place to
> find it.**

## Solution

CampusOne treats exam preparation as a **1-click workspace**.

``` text
College → Branch & Semester → Subject Desk → Unit
                                      ↓
                 Notes + PYQs + Videos + Labs + Senior Tips
                                      ↓
                              Fast Exam Revision
```

We don't replace the college LMS --- **we connect everything around the
student workflow.**

## Key Features

-   📚 **Syllabus-Mapped Notes** --- Unit-wise student and topper
    handwritten notes.
-   📝 **Solved PYQs** --- Five-year university semester paper archives
    with solutions.
-   🎥 **Curated Videos** --- Short, topic-mapped lectures aligned to
    syllabus units.
-   🧪 **Lab Manuals** --- Tested implementations and viva preparation
    guides.
-   📅 **Exam Calendar** --- Midterm, practical, semester, and syllabus
    alerts.
-   🔗 **Official Links** --- Quick access to university ERP and LMS
    portals.
-   👥 **Senior Tips** --- Exam patterns and high-scoring question types
    from previous batches.
-   📊 **Syllabus Tracker** --- Unit-level revision checklists and
    progress tracking.

## Example

**DBMS → Unit 3: Normalization**

A student can find handwritten notes, solved PYQs covering 2NF/3NF/BCNF,
a short revision video, and senior tips in one place.

Instead of:

``` text
Search → Open links → Search again → Ask seniors → Search again
```

CampusOne aims for:

``` text
Select Subject → Select Unit → Study
```

## MVP

The current MVP demonstrates the core academic workflow:

**Login → Subject Dashboard → Unit Selection → Notes/PYQs → Exam
Preparation**

A working DBMS demonstration is prepared around **Galgotias University
Computer Science DBMS Unit 3**, with notes and solved PYQs available for
demonstration.

## Feasibility

CampusOne uses an established full-stack architecture: React, Node.js,
Express, MongoDB, cloud storage/CDN, Vercel, and Render.

The system is designed to work independently of college ERP
infrastructure, reducing dependency on institutional systems.

## Limitations & Risks

### Content Moderation

Student and topper uploads need verification.

**Approach:** peer-voting and verification mechanisms.

### Syllabus Changes

University curricula can change.

**Approach:** dynamic syllabus and resource tagging.

### Cold Start

A new platform needs useful content from the beginning.

**Approach:** seed initial semesters with existing PYQ archives and
curated resources.

CampusOne aims to change the revision workflow from:

> **Frantic multi-platform searching**

to:

> **Instant, syllabus-driven exam preparation**

The goal is to reduce search time, improve organization, and preserve
senior-to-junior academic knowledge.
